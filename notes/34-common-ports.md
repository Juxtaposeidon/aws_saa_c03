# Common Ports

| Type | Protocol | Port | Traffic |
| --- | --- | --- | --- |
| SSH | TCP | 22 | Encrypted |
| HTTP | TCP | 80 | Unencrypted |
| HTTPS | TCP | 443 | Encrypted (TLS/SSL) |
| RDP | TCP / UDP | 3389 | Encrypted |
| FTP | TCP | 21 | Unencrypted |
| SFTP | TCP | 22 (runs over SSH) | Encrypted |
