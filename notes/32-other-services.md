# Other Services

**Device Farm:** test mobile apps on real physical devices in the cloud.

**Amplify:** simplified frontend-to-backend app development/deployment toolkit.

**Serverless Application Repository:** catalog of pre-built, deployable serverless app templates.

**VMware Cloud on AWS:** run your existing VMware stack on dedicated AWS hardware, no re-architecting.

**Elastic Transcoder:** converts media files between formats (older, superseded by MediaConvert).

## AI/ML Services

- **Rekognition:** face detection, labeling, celebrity recognition
- **Transcribe:** speech to text, e.g. subtitles, voice recordings
- **Polly:** text to speech
- **Translate:** translations
- **Lex:** build conversational bots — chatbots
- **Connect:** cloud contact center
- **Comprehend:** natural language processing (NLP). Extract phrases, places, people; find insights
- **Comprehend Medical:** detects information in unstructured clinical text. Detects Protected Health Info (PHI) — DetectPHI API
- **SageMaker:** ML for developers and data scientists
- **Kendra:** ML-powered search engine
- **Personalize:** real-time personalized recommendations
- **Textract:** detect text and data in documents
