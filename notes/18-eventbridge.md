# EventBridge

**EventBridge:** serverless event router with intelligent filtering and multi-destination routing. Native target for **Step Functions** and **Kinesis Data Streams**.

- **Rules:** **rich content filtering** for event buses, e.g. route only events where a specific JSON field matches a value, to different targets.
- **Event Buses:** receive/capture incoming events and route them, e.g. to Lambda/SNS. 1-to-many targets.
- **EventBridge Pipes:** simplify integrations between producers and targets. 1 source → 1 target.
- **Scheduled rules / cron** with Lambda.
- **Archive/replay events.**
- **Schema registry.**
