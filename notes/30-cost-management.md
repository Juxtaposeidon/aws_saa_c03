# Cost Management

| Tool | One-liner |
| --- | --- |
| **Cost Explorer** | Visualize, analyze, filter **historical** spend, **forecast ~12 months** ahead, get **RI/Savings Plan recommendations** |
| **AWS Budgets** | Set cost or usage thresholds, **alert/notify** when exceeded |
| **Cost & Usage Report (CUR)** | **Most detailed, granular** billing data, delivered **to S3**, queried with **Athena** (or QuickSight). SQL |
| **Cost Anomaly Detection** | **ML** watches for **unusual spikes/anomalies** in spend and **alerts you** |
| **Compute Optimizer** | ML **rightsizing recommendations** for EC2 instance size, EBS volumes, Lambda, ASG |
| **Cost Allocation Tags** | Tag resources per team/project, then slice costs by tag. **Activate in the Billing console** |
