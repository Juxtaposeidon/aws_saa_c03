# Application Integration

**AppSync:** GraphQL real-time API for **web/mobile apps** to combine data from multiple backends/microservices. Real-time queries, mutations, subscriptions. DynamoDB, Lambda, RDS, HTTP.

**AppFlow:** sync/transfer data from external SaaS apps (Salesforce, Slack, etc.) into S3/Redshift without custom code.

**Amazon MQ:** managed message broker service (JMS, AMQP) for **migrating legacy applications already built on traditional message brokers** (ActiveMQ/RabbitMQ).
